Git Collaboration Lab

Laboratório prático para aprender Git, GitHub e colaboração em projetos de software.

Objetivos

* Aprender a trabalhar com branches.
* Registrar alterações usando commits.
* Documentar projetos com Markdown.
* Organizar tarefas usando Issues.
* Revisar alterações por meio de Pull Requests.

Como participar

1. Leia as instruções deste README.
2. Escolha uma tarefa aberta na seção Issues.
3. Crie uma branch para sua alteração.
4. Faça commits pequenos e descritivos.
5. Abra um Pull Request para revisão.

Convenção de branches

* feature/: novas funcionalidades.
* fix/: correções de problemas.
* docs/: alterações na documentação.

Convenção de commits

* feat: nova funcionalidade.
* fix: correção.
* docs: documentação.
* test: testes.
* refactor: reorganização de código sem alterar o comportamento esperado.

Regras de colaboração

* Não faça alterações diretamente na main.
* Descreva o motivo de cada mudança.
* Revise o diff antes de abrir um Pull Request.
* Vincule Issues relacionadas aos Pull Requests.
